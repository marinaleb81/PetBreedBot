## Введение

Это руководство описывает шаги для запуска проекта PetPreed на вашем локальном компьютере для разработки и тестирования. Мы будем использовать:
* Базу данных SQLite (файл `pets.db`).
* Веб-сервер Uvicorn для запуска FastAPI бэкенда.
* Ngrok для создания временного публичного HTTPS-адреса, чтобы тестировать интеграцию с Telegram Web App.

## Предварительные требования (Локально)

* Установленный **Python 3** (версия 3.8 или выше рекомендуется).
* Установленный менеджер пакетов **pip**.
* Возможность создавать виртуальные окружения (**venv** или **virtualenv**).
* Скачанный **ngrok** ([https://ngrok.com/download](https://ngrok.com/download)) и зарегистрированный аккаунт ngrok (для более стабильной работы).
* **Код проекта PetPreed**, скопированный или клонированный на ваш компьютер.
* **Токен вашего Telegram-бота** (от @BotFather).
* **(Опционально)** Токен для Mistral API, если хотите тестировать функции, связанные с ним.
* **(Опционально)** Учетные данные Google Cloud (JSON-ключ), если хотите тестировать функции Google Vision API.

## Получение кода проекта

1.  **Клонируйте репозиторий** (если он на GitHub/GitLab):
    ```bash
    git clone <URL_вашего_репозитория> PetPreed_local
    cd PetPreed_local
    ```
    Или **скопируйте** все файлы проекта в одну папку на вашем компьютере (например, `E:\PetPreed\PetPreed_local`).
2.  Убедитесь, что структура проекта сохранена (например, папка `Backend` внутри основной папки, файлы `index.html`, `script.js` и т.д. в корне). Судя по вашим скриншотам, корневая папка это `E:\GitHub\PetBreedBot\PetBreedBot\PetPreed_local\PetPreed\`.

## Настройка окружения Python

1.  **Откройте терминал** (Command Prompt, PowerShell, Git Bash/MINGW64) в **корневой директории вашего локального проекта** (например, `E:\...\PetPreed_local\PetPreed\`).
2.  **Создайте виртуальное окружение:**
    ```bash
    python -m venv venv
    ```
    *(Это создаст папку `venv` в корне проекта)*.
3.  **Активируйте виртуальное окружение:**
    * **Windows (Command Prompt/PowerShell):**
        ```cmd
        .\venv\Scripts\activate
        ```
    * **macOS/Linux/Git Bash:**
        ```bash
        source venv/bin/activate
        ```
    *(После активации в начале строки терминала должно появиться `(venv)`)*.
4.  **Установите зависимости:**
    * **Сначала для бэкенда:** Перейдите в папку Backend и установите зависимости оттуда.
        ```bash
        cd Backend
        pip install -r requirements.txt
        ```
    * **Затем для бота:** Вернитесь в корень проекта и установите `python-telegram-bot` (если его нет в основном `requirements.txt`).
        ```bash
        cd ..
        pip install python-telegram-bot --upgrade
        # Убедитесь, что и другие зависимости, нужные боту (если есть), установлены
        # Возможно, стоит объединить зависимости в один файл или установить из обоих.
        ```

## Конфигурация для SQLite

1.  **Отредактируйте файл `Backend/database.py`:**
    * Найдите строку `SQLALCHEMY_DATABASE_URL = ...`
    * Убедитесь, что она указывает на **файл SQLite**. Файл будет создан в той директории, откуда запускается Uvicorn (т.е. в `Backend`).
        ```python
        # В database.py:
        SQLALCHEMY_DATABASE_URL = "sqlite:///./pets.db"
        ```
    * Убедитесь, что при создании `engine` для SQLite используются `connect_args`:
        ```python
        # В database.py:
        engine = create_engine(
            SQLALCHEMY_DATABASE_URL, connect_args={"check_same_thread": False} # Обязательно для SQLite с FastAPI
        )
        ```
    * Вам **не нужно** использовать `load_dotenv()` или `os.getenv("DATABASE_URL")` в `database.py` для SQLite, если вы жестко прописали путь.

2.  **Настройте файл `.env` (если он используется):**
    * Файл `.env` в папке `Backend` все еще нужен для других секретов.
    * Убедитесь, что там есть ваш `SECRET_KEY` и `TELEGRAM_BOT_TOKEN`.
    * Строку `DATABASE_URL` можно закомментировать или удалить, так как `database.py` теперь настроен на SQLite.
        ```env
        # DATABASE_URL=... (Закомментировано или удалено)

        SECRET_KEY=<Ваш_локальный_секретный_ключ> # Может быть таким же или другим
        ALGORITHM=HS256
        TELEGRAM_BOT_TOKEN=<Ваш_Telegram_Bot_Token>
        MISTRAL_TOKEN=<Ваш_Mistral_Token_если_есть>
        # GOOGLE_APPLICATION_CREDENTIALS=путь/к/локальному/ключу.json (если нужно)
        ```

## Инициализация базы данных (SQLite)

1.  При первом запуске FastAPI/Uvicorn (см. следующий шаг), команда `Base.metadata.create_all(bind=engine)` в вашем `main.py` автоматически **создаст файл `pets.db`** в директории `Backend` и создаст в нем все таблицы, описанные в `models.py`.
2.  Если вам нужны начальные данные, вам потребуется запустить скрипт их заполнения (если он у вас есть) или добавить данные вручную (например, через DB Browser for SQLite).

## Запуск Backend (FastAPI/Uvicorn)

1.  **Откройте ПЕРВЫЙ терминал.**
2.  Перейдите в **корневую директорию проекта**.
3.  **Активируйте виртуальное окружение** (`source venv/bin/activate` или `.\venv\Scripts\activate`).
4.  Перейдите в директорию **бэкенда**:
    ```bash
    cd Backend
    ```
5.  **Запустите Uvicorn:**
    ```bash
    uvicorn main:app --host 127.0.0.1 --port 8000 --reload
    ```
    * `--host 127.0.0.1`: Слушать только локальные соединения.
    * `--port 8000`: Стандартный порт для разработки.
    * `--reload`: Автоматическая перезагрузка при изменениях в коде.
6.  **Не закрывайте этот терминал!** Uvicorn должен продолжать работать. Вы увидите логи FastAPI в этом окне.

## Предоставление доступа через ngrok

1.  **Скачайте ngrok** с официального сайта и распакуйте его.
2.  **(Рекомендуется)** Аутентифицируйте ngrok с помощью вашего токена (он дается после регистрации на сайте ngrok), чтобы снять некоторые ограничения:
    ```bash
    ngrok config add-authtoken <Ваш_ngrok_токен>
    ```
3.  **Откройте ВТОРОЙ терминал.**
4.  **Запустите ngrok**, чтобы он "пробросил" порт вашего локального Uvicorn-сервера (8000) в интернет:
    ```bash
    ngrok http 8000
    ```
5.  Ngrok покажет информацию о туннеле. Найдите строку `Forwarding`, которая выглядит примерно так:
    `Forwarding                    https://<случайный_код>.ngrok-free.app -> http://localhost:8000`
6.  **Скопируйте HTTPS адрес** (например, `https://<случайный_код>.ngrok-free.app`). Это ваш временный публичный URL.
7.  **Не закрывайте этот терминал!** Ngrok должен продолжать работать.

## Запуск Telegram-бота

1.  **Отредактируйте локальный файл `telegram_pet_bot.py`:**
    * Найдите строку `WEB_APP_URL = ...`
    * **Вставьте туда HTTPS адрес, который вы скопировали у ngrok:**
        ```python
        WEB_APP_URL = "https://<случайный_код>.ngrok-free.app/" # Замените на ваш ngrok URL!
        ```
    * Сохраните файл.

2.  **Откройте ТРЕТИЙ терминал.**
3.  Перейдите в **корневую директорию проекта**.
4.  **Активируйте виртуальное окружение** (`source venv/bin/activate` или `.\venv\Scripts\activate`).
5.  **Запустите скрипт бота:**
    ```bash
    python telegram_pet_bot.py
    ```
6.  **Не закрывайте этот терминал!** Бот должен продолжать работать.

## Тестирование

1.  **Проверьте FastAPI:** Откройте в браузере `http://127.0.0.1:8000/api/status`. Вы должны увидеть `{"message":"Pet Adoption API is running"}`.
2.  **Проверьте ngrok URL:** Откройте в браузере **HTTPS** адрес, предоставленный ngrok. Вы должны увидеть ваше приложение (вероятно, `index.html`).
3.  **Проверьте Telegram:**
    * Отправьте команду `/start` вашему боту в Telegram.
    * Нажмите на кнопку "Открыть приложение".
    * Веб-приложение должно открыться внутри Telegram, используя ngrok URL.
    * Поскольку приложение открывается с ngrok URL, а не с `localhost`, **тестовый режим в `script.js` не активируется**, и должна использоваться реальная аутентификация Telegram через `initData`. Протестируйте функции, требующие входа.

Теперь у вас все три компонента (Uvicorn, ngrok, Telegram-бот) запущены локально, и вы можете тестировать связку Telegram Web App -> ngrok -> локальный FastAPI. Следите за логами во всех трех терминалах.
