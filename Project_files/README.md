# Описание проекта "Найди Друга" (PetPreed)

## 1. Обзор проекта

**PetPreed ("Найди Друга")** — это веб-платформа, предназначенная для помощи в поиске и пристройстве домашних питомцев (кошек и собак). Ключевой особенностью является интеграция с Telegram в виде **Telegram Web App (TWA)**, что позволяет пользователям взаимодействовать с платформой непосредственно внутри мессенджера.

Платформа предоставляет функционал для:
* Размещения объявлений о пристройстве питомцев.
* Поиска питомцев по различным параметрам и с использованием референсного изображения.
* Автоматического определения породы питомца по фотографии.
* Поиска пары для вязки питомца.
* Взаимодействия между пользователями (запрос контакта, потенциально чат).
* Управления избранными объявлениями и собственными публикациями.

## 2. Ключевые функции

* **Роли пользователей:**
    * **Ищущий питомца:** Может просматривать объявления, использовать фильтры, поиск по фото, добавлять в избранное, связываться с владельцем.
    * **Пристраивающий питомца:** Может создавать, редактировать и удалять объявления о своих питомцах.
* **Поиск питомцев:**
    * Фильтрация по типу (кошка/собака), полу, возрасту, породе, окрасу, городу, статусу стерилизации/прививок, ключевым словам.
    * Сортировка результатов (новые/старые).
    * Поиск по референсному изображению с автозаполнением фильтров (тип/порода).
    * Отображение результатов списком или сеткой.
* **Размещение объявлений:**
    * Форма для добавления детальной информации о питомце (кличка, пол, возраст, порода, окрас, размер (для собак), город, статус здоровья).
    * Добавление описания и ключевых слов (тегов).
    * Загрузка фотографии питомца.
    * Модерация контента (проверка наличия ровно одного животного на фото, проверка текста на токсичность).
* **Определение породы:**
    * Функция для загрузки одного или нескольких фото питомца с разных ракурсов.
    * Использование Google Vision API для определения типа и вероятной породы.
    * Отображение результата (включая перевод породы на русский) и рекомендаций по уходу (с использованием Mistral API).
* **Поиск пары:**
    * Отдельная форма для поиска партнера для вязки с указанием данных своего питомца.
    * Поиск подходящих объявлений (противоположный пол, тот же вид, порода, город).
* **Аутентификация:**
    * Вход пользователей происходит через их аккаунт Telegram при запуске Web App (`initData` валидация на бэкенде).
    * Бэкенд использует JWT (JSON Web Tokens) для управления сессиями пользователя после первоначальной аутентификации.
    * Предусмотрен тестовый режим для локальной разработки/отладки в браузере с использованием "заглушечного" токена.
* **Взаимодействие пользователей:**
    * Возможность отправить запрос на контакт владельцу понравившегося питомца (владелец получает уведомление в Telegram).
    * (Подразумевается) Наличие функционала чата между пользователями (есть `chat.py`).
* **Личный кабинет (в рамках TWA):**
    * Просмотр и управление списком "Мои объявления".
    * Редактирование и удаление своих объявлений.
    * Просмотр списка "Избранное".
    * Добавление/удаление объявлений из избранного.

## 3. Архитектура и принцип работы

Проект построен на связке Frontend + Backend + Telegram Bot.

* **Frontend:**
    * Реализован как **Single Page Application (SPA)** с использованием HTML, CSS и нативного JavaScript (Vanilla JS).
    * Основной интерфейс представлен в файле `index.html`.
    * Стилизация описана в `style.css`.
    * Вся логика взаимодействия с пользователем, переключения экранов, отправки запросов к API и отображения данных реализована в `script.js`.
    * Использует официальную библиотеку `telegram-web-app.js` для интеграции с Telegram (получение данных пользователя, управление интерфейсом TWA).
    * Запускается внутри клиента Telegram как Web App.
* **Backend:**
    * **API сервер**, написанный на Python с использованием фреймворка **FastAPI**.
    * Отвечает за обработку бизнес-логики, аутентификацию пользователей, взаимодействие с базой данных и внешними сервисами.
    * Использует **SQLAlchemy** как ORM для работы с базой данных и **Pydantic** для валидации данных и определения схем API.
    * Запускается с помощью ASGI-сервера **Uvicorn**.
* **База данных:**
    * В продакшен-окружении используется **PostgreSQL**.
    * Для локальной разработки предусмотрено использование **SQLite** (файл `pets.db`).
    * Содержит таблицы для хранения информации о пользователях (`users`), питомцах (`pets`), объявлениях (`announcements`), сообщениях (`messages`), связях избранного (вероятно, `favorites` association table).
* **Telegram Бот:**
    * Написан на Python с использованием библиотеки **python-telegram-bot**.
    * Обрабатывает команду `/start`, отправляет приветственное сообщение и инлайн-кнопку для запуска Web App.
    * Может использоваться для отправки уведомлений пользователям (например, запросов на контакт).
    * Запускается как отдельный фоновый процесс на сервере.
* **Веб-сервер (Nginx):**
    * Используется на продакшен-сервере как **обратный прокси (reverse proxy)**.
    * Принимает входящие HTTP (порт 80) и HTTPS (порт 443) запросы на доменное имя.
    * Обслуживает статические файлы фронтенда (`index.html`, `script.js`, `style.css`, изображения, иконки).
    * Перенаправляет все запросы к API (`/api/...` или другие роуты FastAPI) на работающий Uvicorn-сервер (обычно на `localhost:8000`).
    * **Терминирует SSL-соединения**, обеспечивая HTTPS (используя сертификат от Let's Encrypt, полученный через Certbot).
* **Внешние API:**
    * **Google Vision API:** Для анализа изображений (определение породы через Web Detection, проверка наличия животных через Object Localization). Требует аутентификации через сервисный аккаунт Google Cloud.
    * **Mistral API:** Для генерации рекомендаций по уходу и проверки текста на токсичность. Требует API-ключ.
    * **Telegram Bot API:** Для взаимодействия бота с Telegram. Требует токен бота.

## 4. Технологический стек

* **Бэкенд:** Python 3, FastAPI, Uvicorn, SQLAlchemy, Pydantic, python-dotenv, python-telegram-bot, google-cloud-vision, google-cloud-secret-manager (опционально), httpx, requests, python-jose, passlib, bcrypt.
* **База данных:** PostgreSQL (Продакшен), SQLite (Локально).
* **Фронтенд:** HTML5, CSS3, JavaScript (ES6+), Telegram Web App API.
* **Веб-сервер:** Nginx.
* **SSL:** Let's Encrypt (через Certbot).
* **Окружение:** Linux (Ubuntu на сервере), Виртуальное окружение Python (venv).
* **Облако (для развертывания):** Yandex Cloud (Compute Cloud VM, Virtual Private Cloud, Security Groups, Cloud DNS).
* **Внешние сервисы:** Google Cloud Vision API, Mistral API, Telegram Bot API.
* **Инструменты:** Git, FileZilla/scp, ngrok (для локальной разработки).

## 5. Обзор файлов проекта (основные)

* **`/` (Корень проекта, например, `/home/ubuntu/PetPreed/`):**
    * `index.html`: Основная HTML-структура приложения.
    * `script.js`: Основной JavaScript файл с логикой фронтенда.
    * `style.css`: Стили для приложения.
    * `icon/`: Папка с иконками интерфейса.
    * `images/`: Папка для общих изображений (логотипы) и для загружаемых фото питомцев (создается и используется бэкендом).
    * `telegram_pet_bot.py`: Скрипт Telegram-бота.
    * `requirements.txt`: (Может быть) Зависимости для бота или общие.
    * `.env`: (Может быть) Переменные окружения для бота.
* **`/Backend/` (Бэкенд FastAPI, например, `/home/ubuntu/PetPreed/Backend/`):**
    * `main.py`: Точка входа FastAPI, инициализация приложения, подключение роутеров, настройка CORS, middleware.
    * `database.py`: Настройка подключения к базе данных SQLAlchemy (`engine`, `SessionLocal`, `Base`).
    * `models.py`: Определения моделей таблиц базы данных SQLAlchemy.
    * `schemas.py`: Определения моделей Pydantic для валидации данных API и форматирования ответов.
    * `auth.py`: Логика аутентификации, работа с JWT, получение текущего пользователя.
    * `auth_telegram.py`: Эндпоинт для аутентификации через Telegram Web App.
    * `users.py`: API эндпоинты для работы с пользователями (профиль, избранное и т.д.).
    * `announcements.py`: API эндпоинты для работы с объявлениями (создание, поиск, редактирование, удаление, запрос контакта, поиск пары).
    * `classify.py`: API эндпоинты для классификации изображений, определения породы, взаимодействия с Google Vision и Mistral API.
    * `chat.py`: (Предположительно) API эндпоинты для функционала чата.
    * `requirements.txt`: Зависимости Python для бэкенда FastAPI.
    * `.env`: Файл с переменными окружения для бэкенда (ключи, токены, URL БД).
    * `breeds_map.json`: Словарь для перевода и сопоставления пород животных.
